# proyectointegrador
Proyecto integrador de POO y Tópicos de calidad

# aqui desarrollaremos la app para el proyecto integrador

## clonar el repositorio a tu pc o lap
git clone https://github.com/juanpqsi279-lgtm/proyectointegrador.git

## crear una rama para tu tarea
git checkout -b nombre-rama
(Ejemplo: feature-login o fix-carrito)

## hacer commits 
git add .
git commit -m "Descripción del cambio realizado"

## subir tu rama al remoto
git push origin nombre-rama

## pull request
- Nunca hagas push directo a main.
- Abre un PR para que tus compañeros revisen el código antes de integrarlo.

# COMANDOS BÁSICOS!!!

## Actualizar el repo antes de trabajar en el 
git pull origin main

## Ver estado de cambios
git status

## Cambiar de rama
git checkout nombre-rama

# BUENAS PRACTICAS
- Usa nombres de ramas descriptivos.

- Haz commits pequeños y frecuentes.

- Escribe mensajes de commit claros (qué hiciste, no cómo).

- Revisa los PR de tus compañeros antes de aprobar.

- Si hay conflictos, resuélvelos en tu rama antes de hacer merge.
